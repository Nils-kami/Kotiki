# 🐱 КОТИКИ

Просто приложение, которое генерирует случайных котов. Зачем? Потому что коты — это жизнь.

<img width="282" height="200" alt="{ABDFAF04-2568-486E-8F3B-C02D84A6A99A}" src="https://github.com/user-attachments/assets/39359119-3597-4ef1-a3d3-435a4903b413" />


### Что умеет:
* 🎲 **Рандом** — жмешь кнопку, получаешь нового кота.
* 🔍 **Поиск** — вводишь тег (например, `smile`, `funny`, `cute`) и получаешь кота по запросу.
* 🎬 **Гифки** — переключаешь галочку и смотришь, как кот двигается.
* 💾 **Сохраняй** — понравился мем? Жми «Сохранить» и забирай себе.

### Как запустить?
1. Качаешь папку `bin`.
2. Запускаешь `app.exe`.
3. Смотришь на котов.

*Всё. Никаких сложных установок.*
